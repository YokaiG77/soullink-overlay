2. L'overlay (OBS)

Dans OBS : source Navigateur, décoche "Fichier local", colle ce lien, largeur 1920, hauteur 1080.

  1. Ton jeu : x 0, y 0, 1280x960 (mise à l'échelle : Point)
  2. Jeu de l'autre : x 1280, y 0, 640x480
  3. Ta cam : x 1280, y 480, 320x180 | sa cam : x 1600, y 480, 320x180
  4. Pour taper la route, les morts, les pseudos : clic droit sur la source, Interagir
