Relais de sauvegarde

Ce navigateur ne permet pas de suivre un fichier. Ouvre cette page dans Google Chrome ou Microsoft Edge sur ton PC.

Choisis ta sauvegarde une seule fois. Chrome ne peut pas lire le dossier d'origine du jeu : utilise la copie créée par installer-copie.bat. Tape %USERPROFILE%\SauvegardeIF-copie dans la barre d'adresse de la fenêtre qui s'ouvre, puis choisis ton fichier File X.rxdata.

Laisse ensuite cet onglet ouvert pendant le live : ton équipe est envoyée à l'overlay à chaque sauvegarde en jeu.
