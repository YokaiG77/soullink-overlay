# Soullink Overlay

Overlay OBS pour les soullinks Pokémon Infinite Fusion, avec équipe lue automatiquement depuis la sauvegarde.

- `index.html` : page d'accueil, génère les liens de la partie
- `relais.html` : à ouvrir dans Chrome ou Edge, lit la sauvegarde et envoie l'équipe
- `overlay.html` : à mettre dans OBS (source Navigateur, 1920x1080)
